# C++ Person Example

This repository contains a small C++ program that demonstrates a `Person` class with public `first`, `last`, and `age` fields.

The program creates a person named John Doe, prints the person's full name through `printFullName()`, and then prints a greeting.

## Build and run

```bash
g++ -std=c++17 test2.cpp -o test2
./test2
```

Expected output:

```text
John Doe
Hello, World!
```
